# Simple SOP Template for Universal Music Store Clients

This SOP is a short, client-friendly guide for reviewing and releasing website work on the Universal Music Store project. It is written so the client can quickly understand what is needed, who is responsible, and what the final output should be.

# SOP: Universal Music Store Release Check

## 1. Goal

This SOP helps us review, test, and release approved website changes safely so the storefront, admin, and backend stay stable for users.

## 2. Person in Charge

- Handled by: Justine P. Lupasi
- Reviewed by: Joevanni P. Lupasi

## 3. What We Need

- A clear request or approved task list
- Access to the repository, hosting, and required admin accounts
- Content, images, product details, or other files needed for the change
- Approval to proceed with the update
- The target release date or priority

## 4. Steps

1. Check the request and confirm what is included in the task.
2. Review the affected pages, APIs, or settings before making changes.
3. Make the approved update in the codebase or content system.
4. Test the changed area on desktop and mobile.
5. Confirm that the storefront, admin, and health checks still work.
6. Deploy or publish the approved version.
7. Send a short summary of what was changed and any follow-up notes.

## 5. Done Checklist

- The requested change matches what was approved
- The updated page or feature works as expected
- No related page, checkout flow, or admin action is broken
- The basic health check passes
- The client has reviewed the result or received the release summary

## 6. Final Result

Final result: The approved Universal Music Store update is completed, checked, and ready for the client to review or use.
